## Darmowy Claude na 6 miesięcy

Anthropic oferuje program **Claude for Open Source** dla osób utrzymujących lub rozwijających projekty open source. Wybrani uczestnicy mogą otrzymać 6 miesięcy Claude Ultra bezpłatnie.

Sprawdź wymagania i złóż oficjalny wniosek:
<https://claude.com/contact-sales/claude-for-oss>

Uprawnienie nie jest automatyczne i zależy od oceny zgłoszenia przez Anthropic. Nie wymagaj od osób trzecich danych konta ani dostępu do płatności i nie korzystaj z fałszywych promocji.
